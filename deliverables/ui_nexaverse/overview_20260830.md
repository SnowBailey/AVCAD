# AVCAD · UI 换肤 NEXAVERSE（2026-08-30）

## 一、做了什么

按阳哥给的 NEXAVERSE 参考图，把交互页面整体调整为「深空 + 霓虹青 / 星云紫 / 品红」的视觉风格，**功能、布局骨架、交互流程全部保持不变**。

| 维度 | 调整前（深蓝星空） | 调整后（NEXAVERSE） |
|---|---|---|
| 底色 | `#05070d` 深蓝黑 | `#03050b` 近黑，对比更强 |
| 主色 | 星蓝 `#4da3ff` + 极光青 | **霓虹青 `#00e5ff`** + **星云紫 `#a855f7`** + **品红 `#f472b6`** |
| 星云辉光 | 蓝 / 紫 / 青 | 左青 `rgba(0,229,255,.13)`、右紫 `rgba(168,85,247,.13)`、下品红 `rgba(244,114,182,.09)` |
| 标题 | 纯白 + 蓝色外发光 | `AVCAD@Bailey@EZPRO` **渐变文字**（白→青→紫→粉） |
| 按钮 | 圆角 10px | **全部胶囊形**（`border-radius:999px`） |
| 主按钮 | 蓝色渐变 | 青 → 紫渐变 + 更强发光 |
| 次要按钮 | 直角描边 | 细描边胶囊，hover 出青色辉光 |
| 卡片 / 弹窗 | 边框 `rgba(126,160,214,.16)` | 边框降到 `rgba(255,255,255,.075)`，发光更克制；弹窗圆角 22px |
| 状态色 | 青 `#35e0c8` / 橙 / 红 | 成功 `#2ee8a0`、警告 `#f0b45f`、错误 `#ff5a6e` |

保留的两条不可删护栏：
- `.hidden,.modal.hidden{display:none!important}` —— 否则导出弹窗会在页面加载时就显示。
- `.layout.wide` 三条规则 —— 保证第 1/2/3 步隐藏右侧面板、左侧 `max-width:960px` 居中。

## 三、过程中发生的事故与修复（必须记住）

**事故**：本想只替换 `<style>` 块，却用 Write 工具把整个 `index.html` 覆盖成 `PLACEHOLDER`，原文件（约 1000 行 HTML+JS）**当场丢失**——项目无 git、无备份、无 Time Machine 快照。

**恢复**：依据 `avcad/ui/app.py` 的全部 API 契约 + `legend_store.py` / `module_confirm.py` 的数据结构 + 三套 e2e 脚本的 DOM 契约，从零重建整页，功能与交互完整复原。

**重建后 e2e 暴露并修掉的 5 个问题**：

1. 页面初始化未预填样例清单 → e2e 直接点「解析清单」解析为空。修：初始化写入 `SAMPLE_BOM`。
2. `btnReimport` 清空了 `STATE.csv` → 后续第④步取不到 bom、第⑤步被 `if(!STATE.csv)` 拦死，**永远不出图**。修：改用 `STATE.reimport` 标志，只切 UI、保留数据。
3. `renderPortRows(i)` 在卡片插入 DOM 前用 `getElementById` 取容器 → 端口行空白。修：新增 `scope` 参数，按作用域查询。
4. 端口行序号占用了 `span.n`（e2e 用它读数量）→ 读到的是序号不是数量。修：序号改 `span.idx`。
5. e2e 断言 `/v[2-9]/` 匹配维护版本号，维护次数累积到两位数后失真。修：改为 `match(/v(\d+)/)` + 数值 `>= 2` 判断。
