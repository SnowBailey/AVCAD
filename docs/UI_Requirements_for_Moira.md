# AVCAD 清单驱动系统图生成 — UI 需求文档（Moira）

> 目标读者：Moira（UI 设计师）  
> 版本：v1.0  
> 日期：2026-08-29  
> 配套说明：本 UI 对应后端渲染引擎 AVCAD，输出格式为 SVG/DXF。界面本身不直接画图，而是驱动 Python 引擎完成「清单 → 图例 → 拓扑 → 出图」全流程。

---

## 1. 项目背景与目标

AVCAD 是一个面向专业音视频系统设计师的自动出图工具。用户通过导入设备清单，经过 AI 辅助识别、图例确认、架构选择，最终生成符合工程制图规范的系统图（SVG/DXF）。

本轮 UI 设计目标：
- 支持从 Excel/CSV/文本导入设备清单；
- 按「清单项 → 图例定义 → 实例展开」三层模型引导用户确认；
- 每型号仅需确认一次图例，后续自动复用并可修改；
- 在生成前提供系统架构参考，并允许用户选择/确认；
- 最终输出 SVG 预览与 DXF 下载。

---

## 2. 用户角色

- **项目经理/系统设计师（阳哥）**：导入清单、确认模块与图例、选择架构、验收图纸。
- **AI 助手**：辅助解析清单、推荐图例、检查冲突。
- **设计师 Moira**：负责本次 UI 视觉与交互设计。

---

## 3. 核心工作流（五步）

```
① 导入清单  →  ② 模块确认  →  ③ 图例定义  →  ④ 参考架构  →  ⑤ 生成结果
     ↓              ↓              ↓              ↓              ↓
 解析品牌/    带品牌型号/     定义端口（输入/   选最优参考     SVG 预览/
 型号/数量/    通用设备/       输出/Dante/       架构+主备       DXF 下载
 类别          不需要出图       控制/卡槽）        + SPOF 校验
```

**关键设计原则**：
- **一次确认，全局复用**：每个型号的图例首次确认后写入 `legend_library.json`，再次遇到同型号自动回填，用户仍可手动修改。
- **清单数量 ≠ 图例数量 ≠ 实例数量**：清单行只决定设备数量；图例决定一个型号的端口形态；实例是图纸上实际摆放的 N 个模块。
- **「不需要出图」仅屏蔽本次出图**，不删除清单记录，便于追溯。

## 4. 界面清单

| 序号 | 界面 | 主要功能 | 入口 |
|------|------|----------|------|
| 1 | 项目首页/清单导入 | 创建项目、导入清单（Excel/CSV/文本）、解析预览 | 启动页 |
| 2 | 模块确认 | 逐型号确认「带品牌型号」「通用设备」「不需要出图」 | 导入完成后 |
| 3 | 图例编辑 | 为每个型号定义端口：类型、数量、位置、卡槽 | 模块确认后 |
| 4 | 参考架构选择 | 选择/确认系统拓扑模板、主备策略、SPOF 检查 | 图例确认后 |
| 5 | 生成结果 | SVG 预览、校验报告、DXF 下载、修改反馈 | 确认生成后 |

## 5. 各界面详细说明

### 5.1 项目首页 / 清单导入

**目标**：让用户低成本开始，快速把现有清单导入系统。

**界面布局建议**：
- 顶部：项目名称输入框 + 最近项目列表。
- 中部：三种导入方式（Tab 切换）：
  - **上传文件**：支持 `.xlsx`、`.csv`、`.txt`；拖拽上传。
  - **粘贴文本**：多行文本框，支持「品牌 型号 数量」等自由格式。
  - **从模板开始**：提供「会议室、舞台、体育场、教室」等 BOM 模板。
- 右侧/下方：解析预览面板，显示识别出的列与示例数据。
- 底部：「下一步：模块确认」按钮，解析失败时置灰并提示。

**关键字段（解析后）**：
| 字段 | 必填 | 说明 |
|------|------|------|
| 设备类型 | 否 | SOURCE / PROCESSOR / MIXER / AMP / SPEAKER 等 |
| 品牌 | 否 | 可为空，空则视为通用设备 |
| 型号 | 否 | 为空时使用通用型号占位 |
| 名称 | 是 | 清单显示名，如「会议话筒(有线)」 |
| 数量 | 是 | 整数，决定生成几个实例 |
| 特性 | 否 | `dante;control;analog` 等，分号/逗号分隔 |
| 参数 | 否 | `inputs=8;outputs=8;channels=4` 等 |
| 冗余 | 否 | NONE / PROCESSOR_BACKUP / LINK_BACKUP / FULL_CHAIN |

**异常状态**：
- 文件解析失败：在预览区红色提示「未能识别列头，请手动映射」。
- 必填字段缺失：高亮缺失行，支持手动补全。

---

### 5.2 模块确认

**目标**：让用户决定每个清单行如何进入下一步。

**界面布局建议**：
- 左侧：清单树/表格，按设备类型分组。
- 右侧：卡片式详情面板，逐型号展示。
- 每个卡片提供三个互斥选项（单选）：
  1. **带品牌型号出图**（推荐）：使用品牌+型号，下一步自动匹配/定义图例。
  2. **通用设备出图**：无品牌型号，使用通用图例。
  3. **不需要出图**：本次不出图，保留在清单中。
- 底部：进度条（已确认 / 总数）+ 「下一步：图例定义」按钮。

**特殊规则**：
- 已存在于 `legend_library.json` 的型号，卡片右上角显示「已有图例，自动回填」标签。
- 数量 > 1 时，显示「将实例化 N 个模块」提示。
- 用户可对同一行的所有实例批量设置，也可展开逐台命名（可选）。

---

### 5.3 图例编辑

**目标**：为每个要出图的型号定义物理端口形态，这是生成图纸的核心输入。

**界面布局建议**：
- 左侧：型号列表（仅包含「需要出图」的型号），已确认打勾，未确认高亮。
- 中部：可视化编辑器（核心区域）：
  - 一个可拖放的矩形代表设备模块。
  - 矩形上叠加四个边：左 / 右 / 顶 / 底，分别对应默认端口位置。
  - 用户通过「添加端口组」按钮，在指定边上添加一组同类型端口，并输入数量。
  - 已添加的端口组用图标/色块表示在对应边上，并显示数量。
- 右侧：属性面板，编辑当前选中端口组：
  - 端口类型：模拟输入 / 模拟输出 / Dante 网络 / 控制 / 自定义卡槽。
  - 数量。
  - 所在边：左 / 右 / 顶 / 底。
  - 标签（可选）。
  - 是否由卡槽提供（`feature_ports=False` 等高级选项，默认隐藏，可展开）。
- 底部：「确认并保存到图例库」+ 「跳过，使用默认」按钮。

**默认端口布局规则（必须遵守）**：
| 端口类型 | 默认位置 | 备注 |
|----------|----------|------|
| 输入（IN） | 左侧底部 | 模拟/数字输入 |
| 输出（OUT） | 右侧底部 | 模拟/数字输出 |
| Dante 网络 | 右侧中部 | RJ45 接口 |
| 控制（RS-232/IP/GPIO） | 顶部 | 控制接口 |
| 自定义卡槽 | 底部 | HY/MY/RY 等卡槽条 |

**可视化反馈**：
- 当端口过多时，自动压缩显示并显示 `+N` 提示。
- 卡槽以底部横条形式展示，标注槽位编号。
- 模块标题区固定三行：名称 / 品牌 / 型号。

**缓存提示**：
- 保存时提示「已保存到图例库，下次遇到同型号自动回填」。
- 提供「恢复默认」按钮，覆盖本次修改但不删除图例库条目。

---

### 5.4 参考架构选择

**目标**：在生成图纸前，让用户选择并确认系统拓扑与冗余策略。

**界面布局建议**：
- 顶部：项目基本信息 + 设备数量统计。
- 左侧：参考架构模板列表（按场景分类）：
  - 通用会议室
  - 无线话筒系统
  - FOH 舞台
  - 分布式系统
  - 主备冗余系统
  - 自定义架构
- 中部：架构缩略图/流程图预览（轻量 SVG 或简图，非最终图纸）。
- 右侧：当前架构配置摘要：
  - 主信号路径顺序；
  - 冗余级别；
  - 交换机数量与位置；
  - SPOF（单点故障）检查结果。

**SPOF 检查展示**：
- 绿色：无单点故障；
- 黄色：存在潜在风险（如主备共用电源），可忽略或修复；
- 红色：严重冲突（如主备共用交换机），必须修改。

**操作按钮**：
- 「生成系统图」：进入最终出图。
- 「返回修改图例」：回到上一步。
- 「选择自定义拓扑」：允许高级用户手动调整链式顺序（可选）。

---

### 5.5 生成结果

**目标**：展示最终图纸，并提供校验与下载。

**界面布局建议**：
- 主区域：SVG 图纸预览（可缩放、平移、全屏）。
- 右侧/底部：生成摘要与校验报告：
  - 设备数量、连线数量、交换机数量。
  - 校验结果：模块重叠数、斜线段数、警告数。
  - 若不通过，列出具体问题行号/设备名。
- 操作区：
  - **下载 SVG** / **下载 DXF**。
  - **标注修改**：用户可在 SVG 上框选区域并填写修改意见（可选，高级）。
  - **重新生成**。

**成功状态**：
- 校验全部通过时显示绿色「PASS ✅」徽章。
- 提供一键生成 `gallery.html` 汇总页（包含所有系统图与自检清单）。

**失败/修改流程**：
- 若用户提交修改意见，系统回到对应步骤（图例编辑或架构选择）。
- 支持逐型号确认/驳回的进度表视图（参考 `deliverables/model_previews/index.html` 的审阅表）。

## 6. 全局组件规范

### 6.1 色彩

沿用后端 SVG 的信号语义色：

| 信号类型 | 颜色（十六进制） | 用途 |
|----------|------------------|------|
| XLR / 模拟 | `#5dcaa5`（青绿） | 模拟音频线 |
| Dante 网络 | `#378add`（蓝） | 网络主路径 |
| AES/EBU | `#3aa6a0`（青） | 数字音频线 |
| SPEAKER | `#e8655a`（红） | 扬声器线 |
| RF | `#e8923c`（橙） | 无线射频 |
| CONTROL | `#b07cd9`（紫） | 控制线 |
| 主路径 | 实线 | 默认 |
| 备路径 | 虚线 | 备份/次要路径 |

界面中性色建议：深色背景（与 SVG 风格一致）或浅色 SaaS 面板任选一种主调；若选深色，模块卡片用 `#26261f` 背景、米白文字 `#f5f5ec`。

### 6.2 字体

- 中文：苹方 / 思源黑体；
- 数字/英文：Inter / SF Mono（等宽用于端口数量）；
- 字号层级：标题 18px，正文 14px，辅助 12px，端口标签 8px。

### 6.3 图标

- 导入：上传图标；
- 模块状态：已确认（✓）、不需要（✕）、未确认（!）；
- 端口类型：每种信号一个颜色+图标组合。

## 7. 状态、错误与边界情况

| 场景 | 期望行为 |
|------|----------|
| 用户导入空清单 | 提示「清单为空，请检查文件或粘贴内容」 |
| 解析到未知品牌/型号 | 标记为「通用设备」，并在图例编辑中提醒用户定义 |
| 同一型号出现多次 | 仅保留一行图例编辑，但实例数量累加 |
| 用户删除已保存图例 | 二次确认；删除后再次遇到同型号需重新定义 |
| 网络异常/后端引擎失败 | 显示错误 Trace ID，保留用户输入，可重试 |
| 图纸校验不通过 | 展示具体不通过项（重叠、斜线、警告），并允许回退 |
| 清单中数量 > 1 | 实例化 N 个模块，UI 中可批量命名也可接受默认名 |

## 8. 响应式建议

- 桌面端：左右分栏布局（列表 + 详情/编辑器）。

- 移动端：仅保留「查看结果」与「简单上传」，复杂图例编辑建议引导至桌面端。
